# 評価と助言の基準

レポートの評価は、読む人が「次に何を変えればいいか」がわかることが目的。点数は相対的な目安で、厳密な採点ではない。迷ったら、データから言える範囲で控えめに書く。

## 栄養の目安

| 項目 | 目安 | 使い方 |
|---|---|---|
| たんぱく質 | 体重×1.6〜2.2 g/日（筋肥大・リコンプ期）。維持なら 1.2〜1.6 | `stats.daily.p_per_kg` と月別の推移で評価する。月別グラフの帯は 1.6〜2.0 g/kg |
| 1食のたんぱく質 | 20〜30 g（体重×約0.4 g） | 食事ごとのたんぱく質グラフの黒線は 20 g。朝食の不足は、このアプリのユーザーに多い |
| 脂質 | エネルギー比 20〜30% | 30% を超えたら、夕食の揚げ物・クリーム系・脂の多い肉が主な原因かを `stats.dinner` と品目で確かめる |
| 炭水化物 | 残りのエネルギー。トレーニング日は多め | 脂質を減らしたぶんを主食と果物に回す、という形で提案する |
| カロリー | 目標の ±10% を「適正帯」とする | `in_band` / `under` / `over` の日数と標準偏差で、ばらつきを評価する |

目標値は settings シートのもの。現状と目標が大きく食い違う場合（例：目標カロリーを上回る月に体重も筋肉も増えている）、目標を見直す提案をしてよい。その根拠には基礎代謝×活動量と、InBody の推移を使う。

## 体組成の読み方

- **まず `intervals` を見る。** 測定の各区間について、体重・体脂肪率・筋肉量の変化と、その間の食事（3食そろった日数、平均 kcal、平均 P）が出ている。体の変化と食事を、区間ごとに対応させる。
- **1回だけ外れた値**（前後の測定から大きく離れ、次で戻る）は、水分・食後・測定時刻による測定ブレの可能性がある。`stats.md` の `possible outliers` に自動で出る（例：前日 49.6 kg・翌日 49.8 kg なのに、その日だけ 47.9 kg）。グラフでは白抜きの点になる。**同じ方向に何回も続く変化**は、本当に起きている変化。前のレポートで後者を「ブレ」と書いてしまい、履歴を見て訂正した。前後を必ず確認する。
- 「期間内の最高値／最低値」と書く前に、`measurements` の一覧で確かめる。測定が抜けたデータで「最高値を更新」と書き、全データを見たら期間はじめのほうが高かった、という失敗があった。
- 短期間の筋肉量の大きな増加（2週間で +1.5 kg など）には、水分や筋グリコーゲンの戻りも含まれる。全部を筋肉と書かない。
- 測定間隔が21日を超える区間は、グラフに「測定なし」の帯が出る。その間の動きは推測しかできないと書く。
- 測定条件（時刻、食前か食後か）がばらついている場合は、「朝・起床後・トイレ後・食事前」にそろえて2週間に1回測るよう勧める。
- 体重がほぼ同じでも、筋肉量と体脂肪率が逆向きに動いていたら、そこが一番の見どころ（リコンプ、または筋肉の減少）。

## 評価のつけ方（grades）

標準の6項目と、スコアの目安。期間の課題に合わせて項目を差し替えてよい（例：間食、記録の偏り）。

| 項目 | 見るもの |
|---|---|
| 体組成 | 筋肉量と体脂肪率の推移。InBody 点数 |
| たんぱく質 | 平均 g/kg、目標達成日の割合、最近の傾向 |
| カロリー量 | 適正帯に入った日の割合、平均と目標の差、ばらつき |
| 記録の継続 | 記録した日の割合、3食そろった日の割合 |
| 脂質コントロール | エネルギー比、目標を超えた日数、揚げ物の頻度 |
| 朝食 | 朝食のたんぱく質とカロリー、P 20 g 以上の朝食の日数 |

文字の目安：S 90〜、A 80〜89、B 60〜79、C 40〜59、D 〜39。`score` は同じ尺度で、メーターの長さになる。総合評価は、体組成とたんぱく質をやや重くした平均で決める。改善傾向がはっきりしていれば `plus: "+"` をつける。

## トレーニングの組み方

運動のログはデータにない。体組成と食事から組み、そのことを `training.lead` に書く。

- 基本は週4回の上半身／下半身分割（上A・下A・休・上B・休・下B・休）。運動習慣がない場合の入り口として、週2〜3回の全身メニューにも触れる。
- 部位別の筋肉量（inbody_detail）で標準の95%を下回る部位があれば、その部位の種目とセット数を増やす。
- 曜日別のカロリーに突出した日があれば、その日を下半身の日にして、トレーニング後に炭水化物を取る形にする（`mark: true`）。
- ルール3枚は、漸進性（ダブルプログレッション）、強度（RPE 7〜9、4週ごとのデロード）、栄養（トレ前後に P 25 g）が基本。データに合わせて入れ替えてよい。
- 痛みや持病がある場合は専門家に相談するよう、注記で一言添える。

## 目標値（targets）の作り方

- 期間は「次の4週間」を基本にする。行は、カロリー、たんぱく質、脂質、炭水化物、一番の課題（朝食の P など）、記録の継続。
- 「具体策」には、その人が実際に食べている品目を使う（`stats.foods`、`stats.breakfast`）。例：トーストだけの朝 → トースト＋卵2個。
- 置き換え表は、脂質やカロリーの大きい品目を、記録によく出てくるものから3〜5個選ぶ。差は「約 −15 g」のように概算で書く。
- チェックリストは、目標表と運動メニューを行動に分解したもの。

## 書き方

- 結論を先に、数字は具体的に、食べ物の名前で書く。
- 褒めるところは、数字の裏付けがあるときだけ、短く。
- 「〜しましょう」を続けすぎない。理由を一言添える。
- 医療的な診断はしない。健康上の懸念（極端な体重減少、内臓脂肪レベル10以上など）があれば、受診を勧める一文にとどめる。
